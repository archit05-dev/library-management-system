# Library Management System

A Java-based Library Management System built to practice Object-Oriented Programming (OOP), software design, exception handling, and version control using Git and GitHub.

## Features

* Add books to the library
* Register users
* Issue books to registered users
* Return issued books
* Display books, users, and transactions
* Track borrowing transactions
* Prevent duplicate transaction IDs
* Validate users and books before issuing
* Menu-driven console interface

## Technologies Used

* Java
* Git
* GitHub

## Project Structure

```text
src/
├── Main.java
└── model/
    ├── Book.java
    ├── User.java
    ├── Transaction.java
    └── Library.java
```

## How to Run

1. Clone the repository.
2. Open the project in VS Code or any Java IDE.
3. Compile and run `Main.java`.
4. Use the menu to interact with the system.

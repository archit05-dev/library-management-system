# Library Management System

A Java-based Library Management System built to practice Object-Oriented Programming (OOP), software design, and version control using Git and GitHub.

## Features

* Add books to the library
* Register users
* Display books, users, and transactions
* Issue books to registered users
* Return issued books
* Track borrowing transactions
* Prevent duplicate transaction IDs
* Validate users before issuing books

## Technologies Used

* Java
* Git
* GitHub

## How to Run

1. Clone the repository.
2. Open the project in VS Code or any Java IDE.
3. Compile and run `Main.java`.
